# Privacy Policy — Password and Note Manager (PNM)

ENGLISH (EN-US)

**Password and Note Manager (PNM)** was built with a strict focus on user privacy and local data security.

## 1. Data Storage
* All of your passwords, notes, and personal credentials are encrypted and stored **exclusively locally** on your device.
* We do not operate external servers, central databases, or any telemetry/tracking systems.

## 2. Cloud Integration (Google Drive & OneDrive)
* The application uses OAuth 2.0 authentication to allow you to back up your encrypted vault directly to your personal cloud storage accounts.
* PNM requests access strictly to its isolated application folder (`approot` / `drive.file`) to read and write backup files created by you.
* Your access credentials (OAuth tokens) and backup files are securely transmitted directly between your machine and the official Google/Microsoft servers without any third-party intermediaries.

## 3. API Credentials (BYOC)
* As an open-source project executed locally, the application relies on API credentials provided by the end-user ("Bring Your Own Credentials").
* The application never collects, shares, or transmits your API keys (`Client ID` / `Client Secret`) or personal data to third parties.

## 4. Contact
If you have any questions regarding the application's execution or source code, feel free to open an Issue on the official GitHub repository.

PORTUGUÊS (PT-BR)

O **Password and Note Manager (PNM)** foi desenvolvido com foco total em privacidade e segurança local.

## 1. Armazenamento de Dados
* Todas as suas senhas, anotações e dados pessoais são criptografados e armazenados **exclusivamente de forma local** no seu dispositivo.
* Não mantemos servidores externos, bancos de dados centrais ou sistemas de telemetria/rastreamento.

## 2. Integração com Nuvem (Google Drive e OneDrive)
* O aplicativo utiliza autenticação OAuth 2.0 para permitir que você realize backups do seu cofre criptografado na sua própria conta de armazenamento em nuvem.
* O PNM solicita acesso estritamente à sua pasta isolada de aplicativo (`approot` / `drive.file`) para ler e gravar os arquivos de backup gerados pelo próprio usuário.
* Suas credenciais de acesso (tokens OAuth) e arquivos de backup são transmitidos de forma segura diretamente entre a sua máquina e os servidores oficiais do Google/Microsoft, sem passar por intermediários.

## 3. Credenciais de API (BYOC)
* Como um projeto de código aberto executado localmente, a aplicação utiliza as credenciais de API fornecidas pelo próprio usuário.
* O aplicativo não compartilha, coleta ou vende suas chaves de API (`Client ID` / `Client Secret`) nem seus dados pessoais com terceiros.

## 4. Contato
Caso tenha dúvidas sobre a execução do aplicativo ou sobre o código-fonte, você pode abrir uma *Issue* no repositório oficial do GitHub.
